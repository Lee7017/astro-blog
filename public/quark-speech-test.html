为什么不测试 MediaStreamTrack.stop()？

Web Speech API 自己管理麦克风音频，网页拿不到它内部的音频轨道。MediaStreamTrack.stop() 只能停止网页通过 getUserMedia() 自行取得的轨道，不保证停止 SpeechRecognition。因此本页面只比较真正能控制识别器的 stop() 和 abort()，并测试两种组合。

如果超时后页面解锁但手机仍显示正在使用麦克风，请关闭该标签页或刷新页面；此时不能认为识别已停止。

本页无需第三方脚本、不会主动上传录音到自建服务器；浏览器的语音识别功能本身可能连接厂商的在线服务。

iPad Safari 可能无法通过 Permissions API 查询摄像头权限，这不代表不能拍照。是否弹授权框要以实际点击测试为准。

2 系统拍照与图库

这两种方式走手机 / iPad 的原生选择界面。网页只能读取你选中的照片，不能直接浏览整个相册。

相机按钮通过 <input type="file" capture="environment"> 请求拍照；图库按钮不设置 capture。具体弹出相机还是选择菜单，由 iPadOS / 浏览器决定。网页不能强迫系统跳过选择界面。

3 网页实时摄像头权限

另一种方法：调用 getUserMedia({video:true})，会向浏览器申请摄像头访问权限。拍完或离开本页会主动停止视频轨道。
